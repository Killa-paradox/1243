# ALTShop Telegram Bot (aiogram 3.x)

Готовый каркас Telegram-бота для персонала проекта ALTShop с ролями `intern`, `seller`, `admin`.

## Возможности
- Авторизация по одноразовому паролю (хранение только хеша пароля).
- Ролевая модель доступа.
- Профиль, общая информация о персонале, статистика.
- Добавление продаж продавцом + модерация администратором.
- Админ-панель: добавление участников, предупреждения, блок/разблок, просмотр состава персонала.
- Еженедельный сброс предупреждений (воскресенье 00:00) через APScheduler.

## Запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Скопируйте `.env.example` в `.env` и укажите токен:
   ```env
   BOT_TOKEN=...
   DB_PATH=bot.db
   ```
3. Запустите бота (любой вариант):
   ```bash
   python -m bot.main
   ```
   или
   ```bash
   python bot/main.py
   ```

## Примечания
- При первом запуске автоматически создаётся/обновляется администратор с Telegram ID `7510792565`.
- Для первого администратора можно вручную создать запись в БД (через sqlite shell/скрипт) или временно добавить seeding-скрипт.
- Все суммы продаж считаются агрегированием подтверждённых записей `sales` за текущий месяц.

- Для совместимости с `passlib` зафиксирована версия `bcrypt==4.0.1`; при проблемах backend используется безопасный fallback `pbkdf2_sha256`.
